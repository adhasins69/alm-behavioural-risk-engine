# ALM Behavioural Risk Engine

A portfolio project demonstrating behavioural modelling for Asset Liability Management (ALM) and Interest Rate Risk in the Banking Book (IRRBB) using fully synthetic banking data.

## Project goal

The project will model how customer behaviour can change the effective cash-flow profile of bank deposits and loans. Planned components include:

- non-maturity deposit rate pass-through (deposit beta)
- deposit stability / runoff behaviour
- retail loan prepayment behaviour
- behavioural cash-flow generation
- IRRBB interest-rate stress testing
- EVE and NII sensitivity
- model validation and monitoring
- an interactive Streamlit dashboard

## Disclaimer

This is an educational portfolio prototype using simulated data. It is not a production banking model, regulatory submission, or claim of regulatory compliance.
